NEXT STEP :2 :create the table in Azure SQL


You need to create the table in Azure SQL 

 Step 1: Go to Azure Portal
 Open:
 Azure SQL → your database → Query Editor

Step 2: Run this SQL
SQL
CREATE TABLE users (
id INT IDENTITY(1,1) PRIMARY KEY,
username VARCHAR(100)
);


Step 3: Click Run
Table will be created

Now test again
Open:
http://<public-ip>
Enter username
Click Save



You should see:
Saved in Azure DB: Anjali

RUN BELOW QUERY TO VERIFY

SELECT * FROM users;
